# Handbook Powerbank 7degrees Model UP1011 Thai/EN Language
### วิธีใช้งาน powerbank `7 degrees UP1011`
#### วิธีการชาร์จอุปกรณ์ (มือถือหรือแท็บเล็ต)
* นำสายชาร์จ USB เสียบเข้ากับช่องพอร์ตจ่ายไฟออก (USB Output) ของพาวเวอร์แบงค์
* เสียบปลายสายอีกด้านเข้ากับสมาร์ทโฟนหรืออุปกรณ์ที่ต้องการชาร์จ
* กดปุ่มเปิด (Power) ด้านข้างตัวเครื่อง 1 ครั้ง (หากไม่มีระบบเปิดอัตโนมัติ) เพื่อเริ่มจ่ายกระแสไฟ 5V/2A
* เมื่อชาร์จเสร็จแล้ว ให้ถอดสายออกได้ทันที

#### วิธีการชาร์จไฟเข้าพาวเวอร์แบงค์
* นำสายชาร์จ (Micro USB หรือ Type-C ตามช่องรับไฟของรุ่น) เสียบเข้าที่พอร์ต Input ของตัวพาวเวอร์แบงค์
* เชื่อมต่อเข้ากับหัวชาร์จบ้าน (Adapter) ขนาด 5V/2A หรือเสียบเข้ากับคอมพิวเตอร์
* สังเกตไฟแสดงสถานะ LED ว่ากะพริบหรือแสดงระดับแบตเตอรี่เต็มแล้วจึงถอด

#### คำแนะนำเพื่อยืดอายุการใช้งาน
* หลีกเลี่ยงการปล่อยให้แบตเตอรี่หมดเกลี้ยง (0%) บ่อย ๆ และไม่ควรชาร์จแช่ทิ้งไว้จนเกินความจ าเป็นเมื่อแบตเตอรี่เต็ม 100%
* รักษาปริมาณแบตเตอรี่ให้อยู่ในช่วง 20% ถึง 80% จะช่วยลดความเสื่อมของเซลล์แบตเตอรี่ได้ดีที่สุด
* เก็บพาวเวอร์แบงค์ไว้ในที่แห้ง อุณหภูมิห้องปกติ และห่างจากความร้อนสูงหรือความชื้น

#### 3 หน้าที่หลักของปุ่มเปิด/ปิด
1. **เช็กปริมาณแบตเตอรี่คงเหลือ (ตอนไม่ได้ชารจ์):** เวลาที่พาวเวอร์แบงค์วางอยู่เฉย ๆ หรือคุณเพิ่งหยิบออกมาจากกระเป๋า แล้วอยากรู้ว่าเหลือแบตเตอรี่เท่าไหร่ ให้กดปุ่มนี้ 1 ครั้ง ไฟ LED จะติดขึ้นมาบอกระดับแบตเตอรี่ทันที (และจะดับไปเองใน 10–20 วินาที)
2. **กระตุ้นการชาร์จไฟออก (Manual Start):** โดยปกติพาวเวอร์แบงค์รุ่นใหม่ ๆ จะมีระบบ Auto-Start เมื่อเราเสียบสายชาร์จกับมือถือ ไฟจะจ่ายทันที แต่ในบางกรณี เช่น มือถือบางรุ่นแบตเตอรี่หมดเกลี้ยง หรืออุปกรณ์ชิ้นเล็ก ๆ (เช่น หูฟังบลูทูธ, นาฬิกาสมารท์ วอทช)์ กินไฟน้อยมากจนพาวเวอร์แบงค์ตรวจไม่เจอ การกดปุ่มนี้ 1 ครั้ง จะเป็นการบังคับให้พาวเวอร์แบงค์ตื่นขึ้นมาและยอมปล่อยไฟชาร์จให้อุปกรณ์ชิ้นนั้นครับ
3. **กดปิดเพื่อตัดไฟ (Force Off):** หากคุณชาร์จมือถือเสร็จแล้ว หรือดึงสายชาร์จออกแล้วแต่ไฟ LED บนพาวเวอร์แบงค์ยังติดค้างอยู่ คุณสามารถกดปุ่มนี้ 2 ครั้งติดกัน (Double Click) เพื่อสั่งปิดการทำงานทันทีเพื่อประหยัดไฟ (แต่ถ้าปล่อยทิ้งไว้เฉย ๆ ระบบก็จะปิดตัวเองโดยอัตโนมัติภายในไม่กี่วินาทีเช่นกันครับ)





#### Description

* No. `1` : Title - Thermometer's title
* No. `2` : Top Area Color - Thermometer's mercury color at top area
* No. `3` : Middle Area Color - Thermometer's mercury color at middle area
* No. `4` : Bottom Area Color - Thermometer's mercury color at bottom area
* No. `5` : Min. Temperature - Mininum temperature of thermometer for display
* No. `6` : Max. Temperature - Maxinum temperature of thermometer for display
* No. `7` : Unit - Unit for display, includes °C and °F
* No. `8` : Scale - Thermometer size for display, includes 'normal' and 'small'
* No. `9` : Number of colors - Able to choose number of color(s) for display on mercury, 1-3 color(s)
* No. `10` : Decimal(s) of Temp. - Able to use temperature value with decimal(s) for display, 0-3 decimal(s)
* No. `11` : Display level % - Able to set display level percentage (Hide/Show).
* No. `12` : Current Temp. Size - Able to set current temperature font size for display (1.2 to 3.2 step 0.2).

### API Input
Using `msg` object.

| Property     | Mandatory   | Type      | Description |
| ------------ |:-----------:|:---------:| ----------- |
| payload      | Yes         | `Number` | Temperature value for display on thermometer |
